MODELE DE DONNEES / DATA MODEL


User / Utilisateur

id : identifiant unique / unique identifier
email : adresse email, unique / email address, unique
password : mot de passe hashe, jamais renvoye au client / hashed password, never returned to the client
firstName : prenom / first name
lastName : nom / last name
role : role de l'utilisateur, ADMIN, MANAGER, STOCK_KEEPER ou SALES / user role, ADMIN, MANAGER, STOCK_KEEPER or SALES
isActive : compte actif ou desactive / whether the account is active or disabled
createdAt : date de creation / creation date
updatedAt : date de derniere modification / last update date


Category / Categorie

id : identifiant unique / unique identifier
name : nom de la categorie, unique / category name, unique
description : description optionnelle / optional description
parentId : identifiant de la categorie parente, optionnel, pour les sous categories / parent category identifier, optional, for subcategories
createdAt : date de creation / creation date
updatedAt : date de derniere modification / last update date


Supplier / Fournisseur

id : identifiant unique / unique identifier
name : nom du fournisseur / supplier name
email : email optionnel / optional email
phone : telephone optionnel / optional phone number
address : adresse optionnelle / optional address
contactPerson : personne de contact optionnelle / optional contact person
createdAt : date de creation / creation date
updatedAt : date de derniere modification / last update date


Warehouse / Entrepot

id : identifiant unique / unique identifier
name : nom de l'entrepot / warehouse name
location : adresse ou zone / address or area
isActive : entrepot actif ou desactive / whether the warehouse is active or disabled
createdAt : date de creation / creation date
updatedAt : date de derniere modification / last update date


Product / Produit

id : identifiant unique / unique identifier
sku : code produit, unique / product code, unique
name : nom du produit / product name
description : description optionnelle / optional description
unitPrice : prix de vente / selling price
costPrice : prix d'achat / purchase cost
unit : unite de mesure, piece, kg ou litre / unit of measure, piece, kg or liter
categoryId : identifiant de la categorie / category identifier
supplierId : identifiant du fournisseur principal, optionnel / main supplier identifier, optional
alertThreshold : seuil declenchant une alerte de rupture / threshold that triggers a low stock alert
isActive : produit actif ou desactive / whether the product is active or disabled
createdAt : date de creation / creation date
updatedAt : date de derniere modification / last update date


Stock

id : identifiant unique / unique identifier
productId : identifiant du produit / product identifier
warehouseId : identifiant de l'entrepot / warehouse identifier
quantity : quantite actuelle disponible / current available quantity
updatedAt : date de derniere modification / last update date
note : la combinaison productId et warehouseId doit etre unique / the combination of productId and warehouseId must be unique


StockMovement / MouvementDeStock

id : identifiant unique / unique identifier
productId : identifiant du produit / product identifier
warehouseId : identifiant de l'entrepot / warehouse identifier
type : type de mouvement, IN, OUT, ADJUSTMENT ou TRANSFER / movement type, IN, OUT, ADJUSTMENT or TRANSFER
quantity : quantite concernee, toujours positive / quantity involved, always positive
reason : motif optionnel, casse, inventaire ou retour / optional reason, damage, inventory count or return
reference : reference optionnelle, par exemple un numero de commande / optional reference, for example an order number
relatedWarehouseId : entrepot lie, uniquement si type TRANSFER / related warehouse, only when type is TRANSFER
userId : utilisateur ayant declenche le mouvement / user who triggered the movement
createdAt : date de creation, ce champ n'est jamais modifie / creation date, this field is never modified


Order / Commande

id : identifiant unique / unique identifier
orderNumber : numero de commande, unique / order number, unique
type : type de commande, PURCHASE pour achat ou SALE pour vente / order type, PURCHASE for a purchase or SALE for a sale
status : statut, DRAFT, CONFIRMED, SHIPPED, RECEIVED ou CANCELLED / status, DRAFT, CONFIRMED, SHIPPED, RECEIVED or CANCELLED
supplierId : identifiant du fournisseur, requis si type PURCHASE / supplier identifier, required when type is PURCHASE
warehouseId : identifiant de l'entrepot concerne / warehouse identifier involved
totalAmount : montant total, calcule depuis les lignes de commande / total amount, computed from the order lines
createdById : identifiant de l'utilisateur ayant cree la commande / identifier of the user who created the order
createdAt : date de creation / creation date
updatedAt : date de derniere modification / last update date


OrderItem / LigneDeCommande

id : identifiant unique / unique identifier
orderId : identifiant de la commande / order identifier
productId : identifiant du produit / product identifier
quantity : quantite commandee / ordered quantity
unitPrice : prix au moment de la commande / price at the time of the order
subtotal : sous total, quantite multipliee par prix unitaire / subtotal, quantity multiplied by unit price


ROLES ET PERMISSIONS / ROLES AND PERMISSIONS

ADMIN
Francais : acces total, gestion des utilisateurs, des produits, des categories, des fournisseurs, des entrepots, du stock, des commandes et des rapports.
English : full access, manages users, products, categories, suppliers, warehouses, stock, orders and reports.

MANAGER
Francais : gere les produits, categories, fournisseurs, entrepots et commandes, consulte les rapports, ne peut pas gerer les utilisateurs.
English : manages products, categories, suppliers, warehouses and orders, can view reports, cannot manage users.

STOCK_KEEPER
Francais : cree des mouvements de stock, consulte le stock et les produits, ne peut pas creer de commandes ni gerer les utilisateurs.
English : creates stock movements, can view stock and products, cannot create orders or manage users.

SALES
Francais : cree des commandes de vente, consulte les produits et le stock, ne peut pas creer de mouvements de stock ni gerer les utilisateurs.
English : creates sales orders, can view products and stock, cannot create stock movements or manage users.
